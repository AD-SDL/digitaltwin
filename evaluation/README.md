# Policy rollout evaluation

Measures a trained VLA policy on the OpenArm cabinet door task in Isaac Lab:
success rate, partial progress, wall-clock cost, inference latency and GPU
load.

Operational walkthrough: [`docs/07_evaluate_policy_rollouts.md`](../docs/07_evaluate_policy_rollouts.md).

## Results

[`RESULTS.md`](RESULTS.md) — measured outcomes for pi05 checkpoint 242000
(~30% success, failure taxonomy, horizon analysis). Per-run detail with every
episode lands in `artifacts/<run>/report.md`, generated by
`scripts/make_report_md.py`.

## Layout

| File | Venv | Role |
| --- | --- | --- |
| `scripts/run_eval.sh` | bash | Orchestrator — starts the server, runs rollouts, reports, tears down. |
| `scripts/policy_server.py` | lerobot | Loads the checkpoint, serves actions over loopback TCP, times itself. |
| `scripts/eval_rollouts.py` | IsaacLab | Headless env, steps the rollout, scores success, writes JSONL. |
| `scripts/eval_wire.py` | both | Length-prefixed `(json meta, raw arrays)` framing. |
| `scripts/gpu_trace.py` | IsaacLab | Background `nvidia-smi` sampler. |
| `scripts/summarize_eval.py` | stdlib | JSONL → report (text or JSON). |
| `scripts/make_report_md.py` | stdlib | JSONL → committable Markdown report with per-episode detail. |
| `artifacts/<run>/` | — | `manifest.json`, `episodes.jsonl`, `gpu_trace.csv`, `report.txt`, `videos/`. |

Rollout videos tile chest + both wrist cameras into one 1280x960 mp4 per
episode (`--video-layout separate` writes one file per camera instead).

## Why two processes

The IsaacLab venv pins `huggingface-hub==1.32.0`; `transformers` requires
`<1.0` and raises `ImportError` on import there. pi05 is PaliGemma +
Gemma-300M and needs `transformers`. So the environment runs in the IsaacLab
venv, the policy runs in the lerobot venv, and they exchange observations and
actions over a loopback socket. Images cross as raw uint8 (~3 MB/step) rather
than JPEG so the policy sees the pixel distribution it was trained on; the
transport cost shows up as the gap between `server total` and `round trip` in
the report.

## Quick start

```bash
CHECKPOINT=/PATH/TO/pretrained_model \
NUM_EPISODES=50 \
evaluation/scripts/run_eval.sh
```
